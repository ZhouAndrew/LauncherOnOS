# Mint Toolbox v0.2 · 分类与扩展槽

## 本次新增

- 工具列表按**功能分类**和**生命周期状态**分别筛选，默认只显示可用入口。
- 24 个原始条目现分为：16 个可用、3 个外部依赖、4 个归档、1 个已移除。
- 旧条目不会误混入常用工具；它们的说明、手册、原脚本仍在包中。
- 可在 GUI 中标记已移除、恢复；删除扩展注册时保留源文件。
- GUI 使用本机原生文件选择器注册任意用户工具，统一表单设置名称、分类和手册。
- 扩展清单保存在用户配置目录，程序升级不会清空。
- 扩展可通过 JSON 声明操作按钮和参数字段；发现时不会执行脚本。
- CLI 与原脚本仍保持可用，增加 `--list --all`、`--extension-add`、`--extension-remove` 等管理命令。

## 验证

- 源压缩包里的全部 24 个原始脚本已逐字节核对，未修改。
- 自动化测试 24 项通过。
- Xvfb 隔离图形环境中 GUI 启动、绘制和截图成功。
- 临时 HOME 内初次安装、覆盖升级和用户扩展目录保留测试成功。
- **尚未在用户 Linux Mint 真机运行可能改变 WordPress / CalDAV / Thunderbird / 文件数据的脚本。**

## 安全说明

- “可用”只意味着入口存在且被启用，不是实际运行成功的保证。
- 取消注册、标记已移除不会删除个人脚本。
- 外部依赖未随安装包重新打包，真实运行可能需要机器原有虚拟环境。
- 不会自动执行导入的扩展。


## v0.2.1 — 禁用与移除同时保留

- 独立新增“禁用/启用”，旧有“标记已移除/恢复”不变；两者可以并存。
- 禁用只阻止工具集启动，不删除原脚本、手册和扩展注册。
- 对已移除工具也可以预先禁用或启用；恢复移除标记不会自动解除禁用。
- GUI/TUI/CLI 同时支持上述两套操作，详细状态显示两者，默认筛选仍优先隐藏禁用与移除。
- 不运行个人脚本，不改变原始程序文件。

## v0.2.2 — 不自动修改筛选器，显示完整执行命令

- 禁用、启用、标记移除、恢复、添加或取消注册都不会改写 GUI 的搜索词、分类和状态筛选器。
- 筛选后暂时不可见的当前工具保留右侧详情，避免管理操作后误选其他工具。
- GUI 直接显示并可复制实际程序命令；填写图形操作参数后展示完整命令。终端在执行前打印命令。
- CLI `--info`、`--run` 以及 TUI 的动作执行都展示可核对的命令行。
- 34 项自动化测试通过（含 Xvfb GUI 交互、筛选条件保留、完整命令及参数安全传递测试）。
- 原始脚本和现有手册保持不变；尚未在用户 Linux Mint 真机验收数据修改操作。
