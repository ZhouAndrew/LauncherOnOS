# Abandoned toolbox direction

The all-in-one Mint Toolbox direction was rejected by the user on 2026-10-31.
Do not use mint-toolbox_0.5.0_all.deb or the toolbox branches as the active product.
The active scope is the independent System Extension Manager under system-extension-manager/.
Its extensions are separately installed/removed Debian packages; the first two are ZIP and Trash and Anki Time Travel.
